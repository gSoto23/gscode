Recursos:

Ejercicios:
  1. GET usuarios:
    GET https://jsonplaceholder.typicode.com/users
    Verificar que devuelva código 200 y una lista de usuarios en formato JSON.
  2. POST crear usuario:
    POST https://jsonplaceholder.typicode.com/users
    Header: Content-Type: application/json
    Body: 
    {
    "name": "Juan Pérez",
    "username": "juanp",
    "email": "juan@example.com"
  }
    Validar que la respuesta sea 201 Created y se incluya un id en la respuesta.
  3. DELETE usuario:
    DELETE https://jsonplaceholder.typicode.com/users/1
    Usar cualquier ID del 1 al 10. Validar que el status sea 200 OK o 204 No Content.

Ejercicios:
  1. Crear tablas:
    CREATE TABLE users (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100)
  );
  
  CREATE TABLE orders (
    id INT PRIMARY KEY,
    user_id INT,
    product VARCHAR(100),
    amount DECIMAL(10,2),
    FOREIGN KEY (user_id) REFERENCES users(id)
  );
  2. Insertar datos:
    INSERT INTO users (id, name, email) VALUES
  (1, 'Ana García', 'ana@example.com'),
  (2, 'Luis Torres', 'luis@example.com'),
  (3, 'Carla Ruiz', 'carla@example.com');
  
  INSERT INTO orders (id, user_id, product, amount) VALUES
  (101, 1, 'Laptop', 1200.00),
  (102, 1, 'Mouse', 25.00),
  (103, 2, 'Monitor', 300.00);
  3. Ejecutar JOIN:
    SELECT users.name, users.email, orders.product, orders.amount
  FROM users
  JOIN orders ON users.id = orders.user_id;

    Resultado esperado:

      name        | email             | product | amount
  ----------------------------------------------------
  Ana García  | ana@example.com   | Laptop  | 1200.00
  Ana García  | ana@example.com   | Mouse   | 25.00
  Luis Torres | luis@example.com  | Monitor | 300.00
